# Tomorin New Tab

[English](README.md) | 简体中文

Tomorin New Tab 是一个轻量、本地优先的 Chrome 新标签页扩展，灵感来自 Infinity New Tab。

## 示例截图

![Tomorin New Tab 示例](docs/assets/example.png)

## 功能

- 替换 Chrome 新标签页。
- 通过 `chrome.search` API 使用 Chrome 默认搜索引擎，也可以切换到 Bing。
- 输入网址时直接打开网址。
- 分页展示常用网站收藏，内置一组少量常用网站。
- 支持全局图标密度：小 / 中 / 大。
- 右下角控制区默认收起到一个透明齿轮，悬停或聚焦时展开。
- 上传的壁纸会尽量保持清晰，保留接近 4K 的分辨率。
- 在常见笔记本分辨率与 Windows 缩放下保持图标尺寸稳定，并自适应收紧网格和垂直间距。
- 不需要账号，不使用统计分析、项目方托管后端或壁纸 API。

### 图标

- 自动为每个网站挑选最清晰的图标：会查看网页声明的图标、网页应用清单（manifest）、苹果触控图标、Google 和 DuckDuckGo 的图标服务，图标太小时还会尝试网站的手机版。每个候选都会实际下载并量出真实尺寸，选最大的方形图标。
- 图标按网站原本的样子显示：只裁掉多余的透明边距，圆角方块、圆形这类图标铺满，透明的标志保持透明，不额外加底板或边框。很小的方形图标会缩小一点放在中间以免模糊，四周接着它自己的底色铺满，看不出边框。
- 完全没有图标的网站，显示带渐变底色的名称首字（中文、英文都可以）。
- 编辑网站时可以在"自动"、各个尺寸的候选、"文字"之间选择，也可以上传自己的图片。
- 图标缓存在本机 IndexedDB 里，之后打开新标签页直接用本地副本。查找图标只会改动本机缓存，不会改动收藏本身，也不会触发同步。

### 编辑

- 右键（触控板双指点按）任意网站进入编辑模式：拖动调整位置，点按图标编辑，点左上角的 × 删除（可以撤销），点击图标以外的任意位置结束编辑。
- 跨页移动：拖着图标到网格左右两侧停一下就会翻页（也可以拖到底部的页码圆点上），再放到想要的格子里。
- 编辑模式下最后一格是"添加"，样式和其他图标一致。

### 同步（可选）

用你自己的服务器，在所有电脑之间同步收藏、排序、图标选择、上传的图标、图标大小和壁纸。

- 换电脑时只需要填写服务器地址和同步密码（在服务器上设置一个你记得住的 `SYNC_PASSWORD`）。
- 新安装的电脑会直接使用云端的收藏，不会把默认网站混进云端。
- 每台电脑第一次同步时，如果本机和云端的收藏不一样，会让你选择"使用云端数据""合并两边"或"使用本机数据"，不会悄悄覆盖。
- 之后每次改动只同步改动的部分：在一台电脑上改名、另一台电脑上挪位置，两边的改动都会保留；两台电脑同时同步也不会互相覆盖。
- 壁纸和上传的图标按内容只上传一次，其他电脑只在缺少时下载。
- 只有本机有改动时才会自动同步：改完几秒后在后台静默上传。没有改动就不会自动同步；要拿到其他电脑的改动，在同步设置里点"立即同步"（本机上传改动时也会顺带取回）。
- 没来得及上传的改动（比如标签页先关了、网络断了），会在下次打开新标签页或网络恢复时补传。
- 第一次同步替换本机数据前，或同步一次删除了多个网站前，会自动保存一份本机备份，可以在同步设置里找回。

部署方式见 [server/README.md](server/README.md)。

## 本地安装

1. 打开 `chrome://extensions`。
2. 开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**。
4. 选择仓库里的 `extension/` 文件夹。
5. 打开一个新标签页。

## 打包

生成可分发的 zip 包：

```bash
./scripts/package-extension.sh
```

zip 文件会输出到 `dist/`。发布和 Chrome Web Store 注意事项见 [docs/release.md](docs/release.md)。

## 从 0.1.x 升级

- 旧数据会在第一次打开新标签页时自动迁移，已缓存的图标会先继续显示，找到更清晰的图标后再替换。
- 同步协议已经更新：请先更新同步服务器，再更新各台电脑上的扩展。旧的访问令牌仍然可以作为同步密码使用。
- 建议先在主力电脑上升级，在同步设置里点"立即同步"，让它成为云端的初始数据；其他电脑也一样点"立即同步"，第一次同步时选"使用云端数据"即可。

## 本地数据

收藏网站、排序和设置保存在 Chrome 扩展本地存储中。壁纸和图标图片保存在扩展自己的 IndexedDB 数据库中。这些数据都只属于当前 Chrome 用户资料，卸载扩展后会被移除。启用同步后，上述数据（包括壁纸和你上传的图标）会发送到你自己配置的同步服务器。
